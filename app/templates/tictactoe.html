Sample Bot Code (Python)

import json
import random

def main():
    data = json.loads(input())
    move_history = data.get("move_history", [])
    board = [[0] * 3 for _ in range(3)]
    for m in move_history:
        board[m["y"]][m["x"]] = m["player"]
    options = [(x, y) for y in range(3) for x in range(3) if board[y][x] == 0]
    if options:
        x, y = random.choice(options)
        print(json.dumps({"x": x, "y": y}))

if __name__ == "__main__":
    main()

I/O Format Specification

Your bot reads one JSON line from stdin and writes one JSON line to stdout.

1. Board

A 3x3 grid, indexed board[y][x] (y=row top→bottom, x=col left→right). Cell values: 0 empty, 1 = X (you, first), 2 = O.

2. Input (Referee -> Bot)

  • move_history (Array): ordered moves, each {"x": int, "y": int, "player": int}.
  • your_side (Integer): 1 for X, 2 for O.

3. Output (Bot -> Referee)

Print your chosen empty cell:

{"x": 1, "y": 1}
